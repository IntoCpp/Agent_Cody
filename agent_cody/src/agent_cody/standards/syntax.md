# Professional Syntax and Grammar Standards

- Correct spelling, grammar, punctuation, capitalization, and typographical errors.
- Preserve the original meaning, facts, tone, and level of detail.
- Make minor wording and sentence-structure improvements when needed for clarity and professionalism.
- Use concise, natural language appropriate for a professional workplace.
- Remove accidental repetition and awkward phrasing without adding new information.
- Preserve meaningful formatting, terminology, names, identifiers, and technical vocabulary.
- Do not summarize, translate, answer, or comment on the text.
- Return only the corrected text.
